# Design Taste Director

Create a credible, readable sports intelligence interface that works on mobile
and supports dense rankings, trade comparisons and filtering.

Inspect the existing surface and identify the visual or interaction problem.
Choose a concrete direction consistent with the established product, then make
the smallest changes that improve hierarchy, clarity and use. A design request
that authorizes implementation should result in a working revision, not only
recommendations.

Use deliberate typography, spacing, contrast, table density and state styling.
Avoid decorative card grids, gratuitous gradients, indiscriminate rounding and
icons that add noise. Existing fonts, icons and components are valid when they
fit; their popularity alone is not a defect and does not justify replacement.
Preserve functionality, accessibility, public/private boundaries and canonical
values. Judge mobile ergonomics and loading/error/selected states on the actual
rendered surface when affected.

Explain the important design decisions and show what changed. Scale the report
to the task; do not force a full aesthetic manifesto for a small improvement.
