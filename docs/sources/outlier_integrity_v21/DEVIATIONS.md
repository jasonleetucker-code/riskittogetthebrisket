## V2.1, Stage 1: the registered repairs (R1–R14, P-1..P-4)

**Status.** Written with the Stage 1 repair implementation, before any V2.1
build of a DEV, R, SPENT or held-out board. **No V2.1 result of any kind exists
when this section is written.** The only inputs read were synthetic rows and the
synthetic payloads of `tests/api/test_outlier_integrity_v21_repairs.py`.

**No acceptance criterion, gate, bar, population, seed, grid, selection rule or
held-out rule has changed.** No mandatory threshold is weakened. Nothing below
loosens a gate. `config/sources/outlier_integrity_v2.json` and V2's records are
untouched. The V2 held-out boards stay SPENT and are not read.

**Flags.** All repairs sit behind one new sub-flag, `outlier_integrity_v21`
(default OFF, `LIVE` gate, effective only with the `outlier_integrity_v2`
master). With it OFF every V2 rule is unchanged, and with the master OFF the
board is byte for byte the incumbent. `dlf_offense_only_vote` stays ON,
`dlf_values_rank_hill_vote` (D4) and `source_freshness_schedule_v2` stay OFF.
Nothing is activated.

The registration leaves some implementation details open. Each choice is
recorded below. Rows marked **(refuses fewer)** make a layer exclude fewer
observations than the most literal reading would. They are flagged for the
independent reviewer, and none of them changes a gate.

| V21-C6 | R5: "use the exact age at the vendor dataset's publication date" | The exact age uses the directory's `birth_date` at the build's `as_of` (the payload's scrape timestamp), in days / 365.2425. A non-integral age is a point. The distance between the two intervals must exceed 1.0 year. | The scrape time is when the vendor CSVs were read, so it is the publication date or later. | V21-C7 | R6: "A refused, held or withheld entry of a rank-signal source keeps its ordinal slot" | A Layer A refusal keeps its value on the row through every ranking pass, and is excluded at the vote (`_source_integrity_vote_exclusions`, status `refused`, existing exclusion shape). B4 holds, B1 / B3 withholds and Layer C drops already kept their slots. A **B2 withhold** (a proven broken payload value with no CSV copy) is still removed at ingestion. B2 sources are value-direct payload copies, and keeping a proven-broken value in place would let it set the site maximum and the IDP backbone. The content hash includes the refused observation, so the build's hash and its board record's hash agree. Because the refused source now appears in the row's `sourceRanks` (the existing vote-level exclusion shape), it is no longer counted in the diagnostic `softFallbackCount`. Confidence is unaffected: its family was scope-eligible before and after, and it votes in neither. | A refusal moves only its own row. No refused value ever votes or is read by a consumer as this player's value. |
