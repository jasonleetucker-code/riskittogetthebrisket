**Status.** Written with the Stage 1 repair implementation, before any V2.1
build of a DEV, R, SPENT or held-out board. **No V2.1 result of any kind exists
when this section is written.** The only inputs read were synthetic rows and the
synthetic payloads of `tests/api/test_outlier_integrity_v21_repairs.py`.

The registration leaves some implementation details open. Each choice is
recorded below. Rows marked **(refuses fewer)** make a layer exclude fewer
observations than the most literal reading would. They are flagged for the
