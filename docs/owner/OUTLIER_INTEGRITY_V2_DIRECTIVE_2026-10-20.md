## PRIMARY OBJECTIVE
Permanently fix the reason adding DLF IDP voting causes legitimate votes from other sources to be incorrectly removed.
Every legitimate, independent fantasy valuation source should have its appropriate voting power, even when it disagrees substantially with other sources.
Reject actual data corruption, incorrect player matches, broken ranking conversions, malformed source feeds, and invalid observations.
Do NOT reject an otherwise valid source simply because its opinion is different from the consensus.
Comprehensive correction of source-validation and outlier-filtering architecture is authorized, with all changes developed and evaluated safely before production activation.
This is not a request to loosen the existing filter until DLF works. Solve the underlying problem correctly, preserving both data integrity and legitimate diversity of opinion.

## 1. START WITH THE EXISTING RESEARCH
Inspect latest repo state and review: PR #1817 (source voting consensus + DLF IDP restoration); PR #1847 (disagreement-preserving outlier policy); src/api/data_contract.py; src/api/outlier_policy.py; src/api/feature_flags.py; source identity-resolution and normalization modules; existing source provenance, freshness, confidence, family-cap infrastructure; existing outlier-filter adversarial and historical-replay tests. Read previous preregistrations and historical evidence. Do not duplicate implementations or discard useful work. Confirmed original failure: the incumbent Hampel filter activates when at least four votes are present. Some IDP ranking sources are converted onto identical or nearly identical numerical values. Adding DLF can therefore change the MAD, collapse the acceptable disagreement range, and cause valid existing source votes to be removed. Previously documented: 31 valid votes incorrectly removed across 30 defensive-player rows; 18 Draft Sharks votes; 10 FantasyPros votes; 3 IDP Trade Calculator votes; seven particularly large player-value changes of ~34–54%. DLF's own contribution was not responsible for most of these large changes; the filter's response to adding DLF was. Eliminate this without weakening the ability to catch actual errors.

## 2. REPLACE ONE-SIZE-FITS-ALL OUTLIER DETECTION WITH LAYERED VALIDATION
Version 2 = coordinated validation pipeline; do not expect one formula to separate every disagreement from every error. At least four questions:

**Layer A — Player identity integrity.** Before any valuation enters voting, verify the observation belongs to the correct player using the existing canonical identity system and all available evidence: canonical player ID, source player ID, Sleeper ID where applicable, name and aliases, position, team, rookie/veteran status, source-specific identity evidence. Do not rely only on similar names. Handle duplicate names, team changes, position changes, rookies, two-way players. Where identity cannot be established reliably, quarantine/mark unresolved per explicit policy. Never silently match a value to the wrong player. V1 detected only 15% of wrong-player adversarial cases — fix at the identity layer, not only by statistical rejection.

**Layer B — Source integrity and normalization.** Verify: correct source format; value scale; rank direction; rank-to-value conversion; positional classification; dynasty/redraft classification; Superflex/TEP assumptions where applicable; freshness and publication timestamps; no missing values silently converted to zero; no invalid historical fallback to an unrelated value curve. Investigate known historical failures: (1) rookie ranking boards voting untranslated within-class ranks; (2) the transient IDP Trade Calculator offense-format anomaly of October 7–8, 2026; (3) any other feed-wide, position-wide or conversion-specific anomalies found in historical replay. Implement source-level and position-level integrity checks where necessary. If a feed or source-position segment is demonstrably corrupted, exclude/quarantine the invalid observations with explicit reason and scope. Do not exclude a healthy source merely because its rankings differ.

**Layer C — Legitimate valuation disagreement (the heart).** Once an observation passes identity, integrity and freshness validation, disagreement is valid opinion, not automatic evidence of corruption. Example: IDPTC 5,000 · FantasyPros 5,100 · DLF 5,000 · Draft Sharks 3,000 → if all pass validation, Draft Sharks retains its vote; consensus incorporates disagreement through the established weighting system. Numerical similarity between separate providers must not cause them to be merged/treated as duplicates; only documented shared-data lineage justifies provider-family consolidation. Keep existing legitimate family caps. Account for rank-to-value translations that produce identical synthetic values without being independent price estimates. A new fourth vote must not trigger arbitrary elimination of previously valid observations.

**Layer D — Confidence and uncertainty.** Disagreement ≠ invalidity. Legitimate disagreement may affect confidence but must not automatically eliminate voting power. Review interaction with confidence classification, independent family count, sparse evidence, source reliability, freshness, weights, consensus calculation. No second confidence engine, no double-counting. Use canonical confidence/weighting logic; any change to uncertainty treatment must be a distinct, explicit, evaluated and documented change.

## 3. RESEARCH THE BEST VERSION 2 ALGORITHM
Do not prescribe an arbitrary formula. Candidates: provenance-aware anomaly detection; position-specific integrity validation; source-wide distribution checks; robust historical source-behaviour comparisons; relative thresholds for extreme deep-tail observations; family-aware robust statistics; independent corroboration; explicit uncertainty handling; structural validation before statistical filtering — only where justified. Do not blindly raise the Hampel threshold or disable filtering. Do not create a filter that keeps nearly everything but lets obviously corrupted values through. If a vote remains statistically suspicious but evidence cannot establish corruption, define a principled treatment rather than pretending it is proven invalid.
