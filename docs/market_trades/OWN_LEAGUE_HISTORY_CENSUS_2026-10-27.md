# Own-league historical trade and draft census — dynasty_main

Phase 1, Lane A of the owner directive *IDP Market Pricing, Acquisition Intelligence, Historical Trade Research, and Draft Strategy* (2026-10-26). Research only: nothing here changes a value, a vote, a verdict or a route. Generated by `scripts/own_league_history_census.py`; every number below is in `docs/market_trades/evidence/own_league_census_2026-10-27.json`.

No hypothesis (H1-H7) is tested here. Phase 2 tests them after a preregistration.

## 1. Method

- **Source.** Sleeper's public read-only v1 API, walked locally across the whole `previous_league_id` chain (`sleeper_client.walk_league_chain_status`). Calls are paced 0.2 s apart, with a bounded retry on HTTP 429. Fetch outcomes: `{'ok': 111}`; failures: 0.
- **Weeks.** Every season league's `/transactions/{week}` for weeks 0-18, plus a probe of weeks 19-25.
- **Trades.** Deduped by `transaction_id` across weeks and seasons. Only `type == trade` and `status == complete` are kept.
- **Prices.** `src.history.asof.batch_known_before` on a scratch temporal ledger built from the tracked `exports/archive/` by `scripts/build_temporal_ledger.py --skip-migrations --ledger <scratch>`. The lookup is instant-strict at the trade's completion time, so a later observation is never selected. Today's value is never used. Missing is never 0.
- **Reuse.** Grouping, topology and fit come from `market_trade_groups` / `market_trade_eval`; formats from `market_trade_format`; picks from `src.identity.picks`; players from `src.identity.resolution` via `market_trade_normalize.IdentityContext`.
- **Privacy.** Transaction-level evidence with roster, user and transaction ids is written only to the gitignored `data/research/own_league_census/`. This file and its JSON carry counts only: no team label (roster order is public, so any order-derived label re-identifies a manager), per-team counts only as quantiles over 3+ teams, and the most active team's share as a bucket. The script refuses to write them if it finds a team label, a per-team field, any 9+ digit run other than the three league ids, or any league member's name.

## 10. Limitations

- Every trade before 2026-07-14 has no point-in-time price in any lane (`before_history_boundary`). The external-archive survey (step 3b) is a separate deliverable; nothing from it is ingested.
- The canonical board lane is absent locally. Archives carry no canonical fields, and the box-only recorder store was not read (owner: no box run). So no trade has a canonical at-the-time price here.
- KTC (`ktcSfTep`) prices no IDP player; IDP price tests can only use IDPTC in this ledger.
- Picks stay unpriced: Sleeper's traded pick is generic-grade, and history holds only slot/tier rows.
- As-of position comes from chain draft metadata where the player was drafted in the chain; otherwise it is the CURRENT Sleeper directory, which may differ from the trade-time position.
- Format comparison uses each season league's settings as fetched now: final settings for completed seasons, current settings for 2026. A mid-season change is not ruled out.
- Manager counts use each season league's final roster ownership; an in-season orphan change is not visible.
- The ledger keeps one archive bundle per UTC date, so same-day intraday revisions are invisible.
